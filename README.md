# Nasi 5 Minit — QR Ordering & Kitchen Display

A QR table ordering and kitchen display system for a busy rice shop that promises every plate within five minutes of the scan. Guests order from their table by QR, every ticket reaches the kitchen screen at once with a five-minute countdown, and the owner runs the menu, the tables and the day's numbers from one dashboard.

**Live demo:** https://kiyoraka.github.io/Project-Nasi-5-Min-Cafe-Management-System/

**Staff sign-in:** any email and any password work.

> This is a demo. The shop, its menu, its staff and every order are fictional, nothing is charged, and everything lives only in your browser tab, so a refresh starts a fresh service.

## Built with

Plain HTML, CSS and JavaScript (ES modules). No framework, no build step and no backend. The photographs were made for this demo.

## Run it locally

The scripts are ES modules, so open the site through a small web server rather than straight from the file:

```bash
python -m http.server 8080
# then open http://localhost:8080
```
